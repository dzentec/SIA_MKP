# MKP — Maritime Knowledge Pack

**Maritime Knowledge Pack (MKP)** — это 100% автономный (offline-first) конвейер для обработки и извлечения знаний из иллюстрированных морских руководств, яхтенных справочников и технической документации (PDF, EPUB, DOCX) с последующим обслуживанием AI-агентов через протокол **Model Context Protocol (MCP)**.

---

## 🧭 Архитектура проекта

Проект разделен на две независимые подсистемы с разделением ответственности:

```
                          ┌────────────────────────────────────────────────────────┐
                          │                      mkp-builder                       │
                          │   (Тяжелый конвейер подготовки данных на Python 3.11)  │
                          └──────────────────────────┬─────────────────────────────┘
                                                     │
         ┌──────────────┬──────────────┬─────────────┴────────────┬──────────────┐
         ▼              ▼              ▼                          ▼              ▼
     [Парсеры]      [OCR Rapid]   [VLM Qwen2.5-VL]          [Верификатор]   [Триплеты]
    Docling / EPUB  EasyOCR/Tesseract   (Prompt 2.0)          (3 ступени)    Сущности/Связи
         │              │              │                          │              │
         └──────────────┴──────────────┴─────────────┬────────────┴──────────────┘
                                                     ▼
                                       ┌───────────────────────────┐
                                       │    .bookpack.zip Архив    │
                                       │ (chunks, assets, manifest)│
                                       └─────────────┬─────────────┘
                                                     │ (Импорт без перестроения)
                                                     ▼
                          ┌────────────────────────────────────────────────────────┐
                          │                       mkp-server                       │
                          │   (Владелец БД: LanceDB Hybrid + LadybugDB Graph +     │
                          │             FastMCP Tools & Resources)                 │
                          └────────────────────────────────────────────────────────┘
```

1. **`mkp-builder` (Конвейер подготовки данных):**
   - **Парсинг документов:** Извлечение текста, геометрии и изображений (Docling для PDF/DOCX, кастомный парсер для EPUB).
   - **OCR маршрутизация:** Автоматическое распознавание текста на схемах и рисунках.
   - **VLM аннотация:** Локальная модель `qwen2.5vl:7b` через Ollama с Prompt 2.0 (дискриминированное объединение типов: `knot`, `maneuver`, `equipment`, `polar`, `map`, `table_figure`, `other`).
   - **3-ступенчатая верификация:** Проверка схемы JSON, перекрестная сверка с текстом и визуальный контроль.
   - **Чанкинг & Граф знаний:** Выделение чанков с `LocationRef` и извлечение триплетов знаний (сущность-отношение-сущность) с мультиязычной нормализацией.
   - **Экспорт архива:** Сборка самодостаточного `.bookpack.zip` с проверкой целостности по SHA-256 (`manifest.json`).

2. **`mkp-server` (Сервер базы знаний MCP):**
   - **Импорт архивов:** Валидация контрольных сумм и добавление книг в локальную базу.
   - **Векторный поиск:** LanceDB с гибридным поиском (Dense векторный + Sparse FTS) и обязательными префиксами `passage:` / `query:` для эмбеддингов `multilingual-e5-large`.
   - **Графовый поиск:** LadybugDB (Kuzu/NetworkX) для поиска связей между морскими терминами, узлами и маневрами.
   - **FastMCP API:** Инструменты `search_chunks`, `get_diagram_image`, `get_related_entities`, `get_book_manifest`.

## 🛠 Используемый стек технологий

| Компонент | Технология | Версия / Модель | Назначение |
| :--- | :--- | :--- | :--- |
| **Среда выполнения** | Python | `3.11+` | Основной runtime |
| **VLM (Vision-LLM)** | Qwen2.5-VL | `qwen2.5vl:7b Q4_K_M` via Ollama | Распознавание и структурирование морских схем |
| **Embeddings** | FastEmbed | `intfloat/multilingual-e5-large` (1024-dim) | Плотные векторные представления |
| **Vector DB** | LanceDB | `≥ 0.17` | Гибридный векторный и полнотекстовый поиск |
| **MCP Server** | FastMCP | `≥ 2.2` (pinned) | Протокол интеграции с LLM-агентами |
| **Парсинг PDF/DOCX** | Docling | `≥ 2.15` | Извлечение структуры и координат |
| **CLI & TUI** | Typer + Rich | `latest` | Терминальный интерфейс с прогресс-барами |

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
# Клонирование репозитория
cd Doc2Rag

# Создание виртуального окружения
python -m venv .venv
.venv\Scripts\activate

# Установка пакета в режиме разработки
pip install -e .
```

### 2. Запуск локального сервиса Ollama

Для работы VLM аннотатора запустите Ollama с поддержкой Flash Attention:

```bash
python poc/start_ollama.py
```

### 3. Сборка цифрового пакета книги (`mkp-builder`)

```bash
# Полная сборка книги с VLM-аннотацией и извлечением триплетов
mkp-builder build \
  --book "path/to/Illustrated_Seamanship.epub" \
  --book-id "dedekam_seamanship" \
  --lang "en" \
  --out "work/demo"

# Быстрая сборка (без вызова VLM и триплетов, для проверки верстки)
mkp-builder build \
  --book "path/to/Illustrated_Seamanship.epub" \
  --book-id "dedekam_seamanship" \
  --skip-vlm \
  --skip-triplets \
  --out "work/demo"

# Экспорт в .bookpack.zip архив
mkp-builder export \
  --book-dir "work/demo/books/dedekam_seamanship" \
  --out "work/demo/out/dedekam_seamanship.bookpack.zip"
```

## 🧪 Тестирование и верификация

В репозитории реализован полный набор юнит- и интеграционных тестов, включая эталонный датасет из 30 вопросов для валидации точности:

```bash
# Запуск всех тестов
pytest tests/ -v
```

### Структура тестовых наборов:
- `tests/test_parsers.py` — Проверка корректности извлечения текста и иллюстраций из EPUB/PDF/DOCX.
- `tests/test_builder.py` — Проверка работы чанкера, верификатора и конвейера сборки.
- `tests/test_export.py` — Валидация создания архивов `.bookpack.zip` и детекция поврежденных SHA-256 манифестов.
- `tests/test_triplets.py` — Проверка мультиязычной нормализации и извлечения графовых триплетов.
- `tests/test_golden_dataset.py` — Валидация структуры и стратификации 30 эталонных вопросов (`qa/golden_dataset.json`).
